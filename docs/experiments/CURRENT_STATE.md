## 下一步及停止条件

详见 [文献与代码核查方案](visual-grounding-route-review-20261125.md)。

1. 首选验证空间读出：冻结同一骨干，对照原头等预算续训、匹配参数量的非空间残差MLP、轻量二维残差定位头。初始输出一致，不默认叠加SADB或竞争。
2. 余弦温度/padding只作常规诊断，不能当独立创新。改变骨干需重新导出特征，不能复用旧缓存。
3. 第一轮预算上限目标60 GPU分钟，先32样本计时。缓存/复现预留20分钟，三个头各最多10分钟，诊断/余量10分钟；超预算缩样或中止。时间为预算上限，非实测完成时刻。
4. 无独立图像验证信号则停止；有信号再做限时短微调和配对随机种子。此前已经查看过val且按val选checkpoint，因此缓存筛选仍是探索性，不伪称新独立测试。正式test留到方法固定。
5. 先证实问题与收益，再查新提炼方法；卷积头、残差、温度、多层融合、LoRA都不能仅凭名称作为贡献。
