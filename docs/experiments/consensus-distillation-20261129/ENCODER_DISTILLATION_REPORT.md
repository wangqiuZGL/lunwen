锚定版每个种子相对原模型仅+0.09765625pp（净2条）。图像聚类5000次bootstrap的95%区间约[-0.097,+0.296]pp，均跨零，不能宣布主指标提升。mIoU比原模型略低约0.01pp，基本持平。它较所测普通训练及无筛选蒸馏更能保留旧性能，但证据只覆盖本512条、短训和最后两层设置，不能外推普遍有效或宣称论文创新。

训练GT只用于原监督与固定教师质量筛选，学生推理不使用GT、教师或翻转。三组同样初始化、样本序列、学习率、步数，原模型2048FP32预测先精确复现。训练使用确定性原图变换来匹配缓存教师，每批断言GT与教师顺序和坐标完全一致。testA/testB没有参与本轮训练、选模或调参。
