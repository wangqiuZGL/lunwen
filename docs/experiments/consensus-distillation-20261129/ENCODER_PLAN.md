# 编码器蒸馏对照训练

2026-11-28。encoder_distill17由原始同一检查点开始。可训练编码器第11/12层（0基10/11）、最终LayerNorm及原定位头，约3134万参数；其余冻结。编码器lr3e-6、定位头lr1e-5，FP32，AdamW1e-4，clip1。

使用官方train内512条原calibration描述，教师为预先固定verified_consensus_0.02；原图确定性val变换匹配缓存教师框，每批断言GT坐标与教师样本顺序精确一致，避免裁剪增强导致教师坐标错误。模型eval模式固定dropout，但打开上述参数梯度；此项不等同全模型训练。

三组native、all_teacher、anchored_quality，种子42/43，相同128步、batch16、相同固定样本序列。native使用原one_ref_loss；其余加2倍教师L1+GIoU。质量接受条件为教师训练IoU>=0.5且比原预测提高>0.01；不接受时锚定原预测。所有样本均有KD监督，避免筛选覆盖率改变有效loss权重。

开发评价固定2048条confirm05 val，FP32、原图单次前向，固定最后一步，不按最好步或最好种子挑结果；原模型先精确复现缓存。testA/testB完全不使用。该验证集此前反复开发，任何正向结果仍需扩大与后续严谨确认，不能称独立测试。总限时1200秒，结束备份结果与权重。
